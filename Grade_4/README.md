# مشروع الصف الرابع الابتدائي (Grade 4 Math) — 2027

مشروع تفاعلي لمادة الماث للصف الرابع الابتدائي وفق منهج المعاصر 2027.

## الوحدات المغطاة:
- **Unit 1: Place Value** (القيمة المكانية، الأعداد الكبيرة حتى الملايين، الصيغ والتقريب).
- **Unit 2: Addition and Subtraction Strategies** (استراتيجيات الجمع والطرح، إعادة التجميع، النموذج الشريطي).
- **Unit 3: Concepts of Measurement** (وحدات القياس المترية للطول والكتلة والسعة والوقت).
