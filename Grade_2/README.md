# مشروع الصف الثاني الابتدائي (Grade 2 Math) — 2027

منصة تفاعلية تعليمية متكاملة لمادة الماث للصف الثاني الابتدائي (First Term 2027) مطابقة لكتاب **المعاصر (El-Moasser)**.

## محتويات المشروع والشباتر المغطاة:
1. **Chapter 1: Graphs and Charts (الرسوم البيانية والجداول الإحصائية)**:
   - معمل استطلاع الألعاب التفاعلي (Toy Survey Lab) وتعبئة الأعمدة من الأسفل إلى الأعلى.
   - جدول التكرار (Frequency Chart) وقراءة البيانات ومقارنتها.
   - أسئلة تفاعلية فورية بالنجوم والأصوات.

2. **Chapter 2: Vertical Addition (الجمع الرأسي وإعادة التجميع)**:
   - آلة الجمع الرأسي خطوة بخطوة بالقيم المكانية (Ones & Tens).
   - تمثيل المكعبات والأعمدة (Base-10 Blocks).
   - إعادة التجميع والترحيل (Regrouping / Carrying Over).
   - ميزان خاصية الإبدال التفاعلي (Commutative Property Sandbox).

3. **Chapter 3: Vertical Subtraction (الطرح الرأسي والتحقق بالجمع)**:
   - آلة الطرح الرأسي والشطب (Cross-out Base-10 Blocks).
   - الاستلاف وإعادة التسمية (Borrowing / Regrouping).
   - روبوت التحقق بالجمع الذكي (Checking Subtraction using Addition).

4. **تحدي البطل الصغير (Comprehensive Quiz)** مع شهادة إتمام وألعاب صوتية وتأثيرات احتفالية.
