# مشروع الصف الخامس الابتدائي (Grade 5 Math) — 2027

مشروع تفاعلي لمادة الرياضيات للصف الخامس الابتدائي وفق كتاب سلاح التلميذ للعام الدراسي 2027.

## الوحدات المغطاة:
- **الوحدة 1: القيمة المكانية للأعداد العشرية وحسابها** (الأجزاء من ألف، تغيير القيمة، المقارنة، والتقريب، وجمع وطرح الكسور العشرية).
- **الوحدة 2: العلاقات بين الأعداد** (المعادلات والمتغيرات، تحليل العوامل الأولية، ع.م.أ وم.م.أ).
- **الوحدة 3: ضرب الأعداد الصحيحة** (نموذج مساحة المستطيل، خاصية التوزيع، الخوارزمية المعيارية).
